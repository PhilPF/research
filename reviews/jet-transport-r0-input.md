Notice that jet transport is not a property that must be satisfied by a
method for all vector fields in a large enough class. Of course, the class
should be as large as possible, as that strengthens the hypothesis and
allows for a better classification of methods. I say a large class, because
I am not sure if it is possible to state it for all vector fields. This game
must be played for all other parts of the puzzle. We don't want this for a
trivial Weil algebra, we want it for all that make sense. Or even other
extensions which are not Weil lifts if those make sense with jet transport
too. The idea, of course, is to understand what jet transport is, and see
how that allows us to strengthen the hypothesis. For example, does it make
sense to consider extensions wrt to parameters or time or the initial
value? Can we use a distinct extension per coordinate of the original
system? What about nested extensions? What about nesting extensions on the
initial value with extensions in time with extensions in parameters over
and over? What about extensions which have Weil algebras of the same
dimension? They may be isomorphic, so the method may need to respect some
change, that seems to impose extra structure. If all of the above make
sense, jet transport is much more that what seems a priori, as it is a
combination of all these facts, not only accepting the extension to a Weil
algebra.
